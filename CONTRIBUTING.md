# Contributing to the Personal Finance Tracking App

Thank you for considering contributing to our personal finance tracking app! Here are some guidelines to help you get started:

## Getting Started
1. **Fork the repository**: Click on the 'Fork' button at the top right of the page.
2. **Clone your fork**: Use `git clone <your-fork-url>` to clone your fork to your local machine.
3. **Create a new branch**: It's a good practice to create a new branch for your work. Use `git checkout -b <your-branch-name>`.

## Contributing Guidelines
- **Code Style**: Follow the coding style employed in the project. Ensure your code is clean and well-commented.
- **Testing**: Please include tests for your contributions. Ensure all tests pass before submitting your pull request.
- **Documentation**: Update the documentation related to your changes. This helps other contributors understand your work.
- **Commit Messages**: Write clear and concise commit messages. Use the format: `type: short description` (e.g., `fix: corrected bug in calculation`).

## Submitting Changes
1. **Push Changes**: After making your changes, push your branch to your fork using `git push origin <your-branch-name>`.
2. **Pull Request**: Visit the original repository and click the 'New Pull Request' button. Provide a clear description of your changes and why they are necessary.

## Issues
If you encounter any issues while contributing or have questions, feel free to open an issue in this repository, and we'll be happy to assist you!

Thank you for contributing!
